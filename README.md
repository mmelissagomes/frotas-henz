# 🚛 Controle de Frotas – Frota Henz

Sistema web desenvolvido para controle logístico da Frota Henz, com foco em organização, agilidade e visual moderno. O projeto foi estruturado com capricho, seguindo padrões elegantes de layout e experiência do usuário.

## 💡 Funcionalidades

- 🔐 Autenticação de usuário com tela de login estilizada (glassmorphism + logo animada)
- 🧭 Página inicial com navegação intuitiva
- 📊 Geração de relatórios mensais por veículo ou frota completa (PDF)
- 📁 Estrutura modular separando telas, estilos e dados
- 🎨 Identidade visual personalizada com gradientes animados, marca d’água e imagem institucional

## 🛠️ Tecnologias utilizadas

- **HTML5** e **CSS3** com animações modernas
- **Django (Python)** para renderização das páginas e gerenciamento de dados
- **Git** + **GitHub** para controle de versão e colaboração
- **VS Code** como ambiente principal de desenvolvimento
